# 03 · 本地化约定

## 两条路

1. **代码内联**（现在用的）：在模型里 override `Localization` 属性。
   优点是不用打包 json，缺点是**只能有一种语言**。
2. **pck 里的 json**：`localization/<lang>/<table>.json`，可多语言。

现在整个 mod 走的是第 1 条，所以 `characters` / `cards` / `relics` 的中文都是代码里写死的。

## 机制

BaseLib 在 `ModelDb.Init` 之后（`ModelLocPatch`）遍历所有模型：

- 模型实现 `ILocalizationProvider` 且 `Localization != null` 时，
- 按 `ModelId.Category` 决定写进哪张表：

| 模型基类 | 表名 |
| --- | --- |
| `CustomCardModel` | `cards` |
| `CustomCharacterModel` | `characters` |
| `CustomRelicModel` | `relics` |
| `CustomPotionModel` | `potions` |
| `CustomPowerModel` | `powers` |
| `CustomOrbModel` | `orbs` |
| `CustomMonsterModel` | `monsters` |
| `CustomEventModel` | `events` |

- 写入的 key 是 `<ModelId.Entry>.<字段名>`。

也可以 override `LocTable` 手动指定表名。

## key 怎么推

类名 → `ModelId.Entry`（CamelCase → UPPER_SNAKE），再加字段名：

| 类 | ModelId | 完整 loc key |
| --- | --- | --- |
| `MyChar` | `character.MY_CHAR` | `characters.MY_CHAR.title` |
| `MyCharStrike` | `card.MY_CHAR_STRIKE` | `cards.MY_CHAR_STRIKE.title` |
| `MyCharStarterRelic` | `relic.MY_CHAR_STARTER_RELIC` | `relics.MY_CHAR_STARTER_RELIC.title` |
| `MyCharCardPool` | `card_pool.MY_CHAR_CARD_POOL` | — |

所以**改类名就会改 loc key**，改类名时要一起改任何按 key 引用的地方。

## 便捷 record

`BaseLib.Abstracts` 里给了三个 record，会隐式转成 `List<(string,string)>`：

```csharp
// 卡牌
public override List<(string, string)>? Localization => new CardLoc(
    "裂风斩",
    "造成{Damage:diff()}点伤害。获得{Block:diff()}点[gold]格挡[/gold]。");

// 遗物（多一个 flavor）
public override List<(string, string)>? Localization => new RelicLoc(
    "余烬之心", "战斗结束后，回复{Heal}点生命。", "仍有余温的灰烬。");

// 角色（字段最多，末尾可加任意额外 key）
public override List<(string, string)>? Localization => new CharacterLoc(
    Title: "阿尔法", TitleObject: "阿尔法", Description: "...",
    PronounObject: "他", PronounSubject: "他", PronounPossessive: "他的",
    PossessiveAdjective: "他的", AromaPrinciple: "...",
    EndTurnPingAlive: "...", EndTurnPingDead: "...", EventDeathPrevention: "...",
    GoldMonologue: "...", CardsModifierTitle: "...", CardsModifierDescription: "...",
    ExtraLoc: new[] { ("unlockText", "阿尔法已可供选择。") });
```

`CharacterLoc` 的 14 个字段缺一不可（都是必填位置参数）。

## 动态变量占位符

描述文本里的 `{...}` 必须对应 `CanonicalVars` 里定义过的变量名：

```csharp
protected override IEnumerable<DynamicVar> CanonicalVars => new DynamicVar[]
{
    new DamageVar(8m, ValueProp.Move),
    new BlockVar(5m, ValueProp.Move),
};
// 描述里就能用 {Damage} / {Block}
```

常用：

| 写法 | 含义 |
| --- | --- |
| `{Damage}` | 当前伤害值 |
| `{Damage:diff()}` | 带升级差值（未升级时显示 `8`，升级后 `8+3`） |
| `{Block}` / `{Block:diff()}` | 格挡 |
| `{Heal}` | 治疗 |
| `[gold]文字[/gold]` | 金色高亮 |
| `[blue]文字[/blue]` | 蓝色高亮 |

变量名要和 `CanonicalVars` 里的一致，否则运行时是空串或报错。

### 简写（SimpleLoc，可选）

BaseLib 支持更短的写法，需要在初始化时开：`SimpleLoc.EnableSimpleLoc("MyChar")`。

| 简写 | 等价于 |
| --- | --- |
| `!D!` | `{Damage:diff()}` |
| `!B!` | `{Block:diff()}` |
| `*文字*` | `[gold]文字[/gold]` |
| `$文字$` | `[blue]文字[/blue]` |
| `[E]` | 能量图标 |

现在没用这套，写的是完整形式，可读性更好。

## 要多语言怎么办

1. 删掉模型里的 `Localization` override；
2. 在 `src/MyChar/assets/localization/<lang>/<table>.json` 放：

```
src/MyChar/assets/localization/eng/cards.json
src/MyChar/assets/localization/zhs/cards.json
```

打包后路径是 `res://MyChar/localization/<lang>/<table>.json`。
（游戏按路径里的 `localization` 段识别，`<lang>` 用 `eng` / `zhs`。）

3. json 内容就是 key → 文本：

```json
{
  "MY_CHAR_STRIKE.title": "Strike",
  "MY_CHAR_STRIKE.description": "Deal {Damage:diff()} damage."
}
```

注意：`assets/` 下任何 `.json` 都会被原样打进 pck，这是 PckPacker 支持的。

## 其它文本

| 内容 | 位置 |
| --- | --- |
| 角色台词 / 口头禅 | `CharacterLoc` 的对应字段 |
| 遗物风味文本 | `RelicLoc` 的 `Flavor` |
| 关键词 tooltip | `BaseLib.Utils.TooltipSource`（见 `ref/BaseLib/BaseLib.Utils/`） |
| mod 名称 / 描述 | manifest `MyChar.json` 的 `name` / `description` |
