## 改 id / 类名前缀

现在 id 是 `MyChar`。要改名的话，需要同步改：

- `MyChar.csproj` 的 `<AssemblyName>`
- `pack/MyChar/MyChar.json` 的 `id` / `pck_name`
- `MyCharAssets` 里的 `res://MyChar/images/` 前缀
- `tools/build.ps1` 里的 `$modId`
- 目录名 `pack/MyChar`、`src/MyChar`、`src/MyChar/assets`

改 `AssemblyName` 或类名还会连带改 `ModelId` 和本地化 key（见 03）。
