## 3. 待确认问题（Q1–Q8）

- **Q1｜起始遗物图标**：`阿尔法芯片` / `伽马芯片` 是给现有两个起始遗物（自我升级 / 自我进化）的新图标，还是**打算新增两枚遗物**（α 芯片 / γ 芯片）？若是新遗物，效果是什么？（没看到 β 芯片。）
- **Q2｜战损图用途**：`战斗70%/50%/20%` 是打算做「随生命降低逐级战损」的立绘机制，还是仅素材留存？
  ⚠ **其中 `战斗20%.png` 是全裸图**。这类露骨素材我不会接进战斗/任何游戏内立绘。若要做战损机制，建议只用 `战斗70%` 这一档（或另出「擦伤/破损」版）；请告知你的真实意图。
- **Q3｜选人三组关系**：`选人1` / `选人2` / `选人背景(+柔和)` —— 哪个是最终选人界面背景？`选人1/2` 是备选方案吗？「柔和」版是给**背景**用（前景人物由 `选人按钮` 提供）还是另有用途？
- **Q4｜α 前缀旧稿**：`α商店` / `α战斗` / `α失败`（旧）——是保留做「α 形态」差分，还是**旧稿可弃**？（`α失败` 是目前唯一的战败图。）
- **Q5｜卡图覆盖率**：卡图只给了 3 张协议 Token。其余 94 张卡的正式卡图**后续再给**，还是这一批先只替换这 3 张？
- **Q6｜目录归置**：3 张药水 + 能量图仍在 `.artwork/` **根目录**（没进子文件夹）。要不要我把它们归到 `药水/`、`UI/` 子目录（仅整理，不动文件内容）？
- **Q7｜尺寸 / 裁切规则**：源图是高分辨率（如 1248×1664），游戏槽位尺寸各异（combat 512²、select 132×195、hud 128²…）。
  希望我**按槽位自动缩放 + 居中裁切**，还是你会按槽位出好图？「柔和」「70%」这类后缀要不要带到 mod 内路径？
- **Q8｜未跟踪素材**：`.artwork/` 是否还有**已废弃、可忽略**的图（如 `raw/` 整目录、`α*` 三张）？
