## 2. 卡图是怎么做的（回答你的问题）

卡图占位图由 **`tools/make_alpha_cards.py`** 生成，一张 500×380 的 PNG，纯代码画：

1. **底色**：竖向渐变 `(34,34,42) → (18,18,24)`（深灰蓝）；
2. **主色**：按卡的类型取一个强调色 —— 攻击 `(198,84,72)` 红 / 技能 `(86,156,214)` 蓝 / 能力 `(156,110,196)` 紫 / 协议系 `(96,196,196)` 青；
3. **主色元素**：顶部 14px 光带 + 中央菱形描边（内填半透明主色）+ 四周 3px 描边；
4. **文字**：底部居中用**微软雅黑 40px** 写**卡名**，顶部居中写 `PLACEHOLDER`（提示是占位图）；
5. 输出到 `src/MyChar/assets/images/cards/<slug>.png`，卡牌代码里用 `MyCharAssets.Card("<slug>")` 指向它。

所以**占位图上写着卡名**——这正是第 9 点问题的来由：某张卡借用了别人的 slug，卡面就会显示**别人的卡名**。
换真美术时**不用改代码**，只要用同名文件覆盖即可（尺寸保持 500×380）。

> 生成脚本要带 PIL 的解释器：`E:\Anaconda\python.exe tools\make_alpha_cards.py`（托管 Python 3.13.12 没有 PIL）。
> 新增校验脚本 `tools/check_card_art.py`：把「卡名 ↔ 图上写的名字」逐张比对，顺便报「引用了但没有的图」和「生成了但没人用的图」。**不需要 PIL**。
