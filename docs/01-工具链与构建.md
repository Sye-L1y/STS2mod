## 构建

```powershell
# 只编译 + 暂存到 pack\MyChar
.\tools\build.ps1

# 编译并部署到游戏（重启游戏生效）
.\tools\build.ps1 -Deploy

# 游戏装在别处
.\tools\build.ps1 -Deploy -GameDir "D:\...\data_sts2_windows_x86_64" -ModsDir "D:\...\mods"
```

产物（`src\MyChar\bin\Release\`）：

- `MyChar.dll` — 程序集，名字必须 == manifest 的 `id`
- `MyChar.pck` — Godot 资源包，名字必须 == `<id>.pck`

三个文件（`MyChar.json` / `MyChar.dll` / `MyChar.pck`）平铺放在 `mods\MyChar\` 下，游戏就能识别。

## 关键坑：PckPacker 的 .NET 版本

`BSchneppe.StS2.PckPacker` 自带的 `PackPck` target 会直接执行它内部的
`tools/net9.0/any/StS2PckPacker.dll`。本机没有 .NET 9 运行时，会报：

```
You must install or update .NET to run this application.
Framework: 'Microsoft.NETCore.App', version '9.0.0'
```

**解决方式**（已写进 `MyChar.csproj`，不用手动改环境变量）：

1. `<PckPackerEnabled>false</PckPackerEnabled>` 关掉包自带的 target；
2. 自己写一个 `PackModPck` target，用 `EnvironmentVariables="DOTNET_ROLL_FORWARD=LatestMajor"`
   让 net9.0 的工具跑在本机的 .NET 10 运行时上；
3. `PackageReference` 加 `GeneratePathProperty="true"`，用 `$(PkgBSchneppe_StS2_PckPacker)`
   引用包目录，避免写死版本号。

所以 `dotnet build` 直接可用，不需要装 .NET 9，也不需要 Godot。

## pck 内部路径映射

```
src/MyChar/assets/images/char/select.png
  -> pck 内：MyChar/images/char/select.png
  -> 游戏里：res://MyChar/images/char/select.png
```

前缀 `MyChar` 来自 csproj 的 `PckPackerResPrefix`，源目录来自 `PckPackerSourceDir=assets/`。

打包时：

- `.png` → 转成 Godot 的 `.ctex`（GST2 头 + 无损 WebP），并生成 `.import` 重映射文件
- `.json` → 原样拷贝
- **`.tscn` / `.gdshader` / `.gdscript` 不支持** → 需要动画场景时必须改用 Godot 导出（见下）

## 校验 pck

`tools/pck.py` 是纯标准库的 Godot 4 pck 读取器：

```powershell
python tools\pck.py list    src\MyChar\bin\Release\MyChar.pck
python tools\pck.py extract src\MyChar\bin\Release\MyChar.pck out\ 
python tools\pck.py cat     src\MyChar\bin\Release\MyChar.pck MyChar/images/char/select.png > x.png
```

## 什么时候才需要 Godot

只有要做**场景类资源**时才需要，比如：

- 战斗立绘 `CustomVisualPath`（`creature_visuals/<id>.tscn`，含 Spine 骨骼动画）
- 能量计数器 `CustomEnergyCounterPath`
- 休息处 / 商人动画 `CustomRestSiteAnimPath` / `CustomMerchantAnimPath`
- 选人背景 `CustomCharacterSelectBg`
- 角色图标场景 `CustomIconPath`

这些现在都还沿用 `PlaceholderID = ironclad` 的本体场景。`tools/godot-mono.zip` 是备用的
Godot 4.5.1 mono 版编辑器，做真立绘时再用。
