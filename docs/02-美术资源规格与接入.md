# 02 · 美术资源规格与接入

## 尺寸规格

尺寸是从本体 / 现成角色 mod 的 `.pck` 里读 `CompressedTexture2D` 头量出来的，不是猜的。

| 用途 | 尺寸 | 说明 |
| --- | --- | --- |
| 卡图 | **500 × 380** | 注意不是 4:3 的 500×375 |
| 选人界面按钮图 | **132 × 195** | 竖版 |
| 选人界面未解锁图 | 132 × 195 | 由按钮图去饱和 + 压暗派生 |
| 顶部栏角色头像 | **128 × 128** | Modder's Manual 写的 88×88 是错的 |
| 头像描边（剪影） | 128 × 128 | 纯白剪影，顶部栏用它上色描边 |
| 遗物图标 | **256 × 256** | 图鉴大图 / 局内小图标暂时共用 |
| 卡面能量图标 | **74 × 74** | 本体 `energy_<pool>.tres` 的 atlas region 实测 |
| 内联能量图标 | **24 × 24** | 本体 `sprite_fonts/<pool>_energy_icon.png` 实测 |
| 药水图标 | **256 × 256** | 本体大图实测；局内槽位按 `keep-aspect` 缩到 60×60，故一张图同时当 packed / large |
| 选人背景 | 2560 × 1200 | 场景图，装进 `select_bg.tscn`（全屏 Sprite2D） |
| 战斗立绘 | 200 × 320 内缩放 | 场景图，装进 `creature_visuals.tscn`（含 defeat 败北立绘） |
| 商店立绘 | 220 × 420 内缩放 | 场景图，装进 `merchant.tscn` |
| 火堆立绘 | 300 × 340 内缩放 | 场景图，装进 `rest_site.tscn` |

## 目录结构

```
.artwork/raw/                 ← 原始图（jpg/png 都行，不参与打包）
.artwork/                     ← 场景源图（选人背景.png / α战斗.png 等，中文文件名）
src/MyChar/assets/images/     ← 处理后的成品，会被打进 pck
    char/    portrait.png  select.png  select_locked.png  hud.png  hud_outline.png  combat.png
    cards/   strike.png  defend.png  blast.png  ward.png  signature.png
    relics/  ember_heart.png  old_anchor.png
    potions/ temp_protocol.png  exp_record.png  special_param.png
    ui/      energy_big.png  energy_text.png
    scene/   select_bg.png  combat.png  defeat.png  merchant.png  rest_site.png
src/MyChar/scenes/            ← 手写场景 .tscn（build 时由 pck_append.py 追加进 pck）
    select_bg.tscn  creature_visuals.tscn  merchant.tscn  rest_site.tscn
```

`.artwork/raw/` 只放源图，**不要**放进 `assets/`，否则会被打进 pck 白白增大体积。

## 处理流程

```powershell
# 依赖 Pillow + numpy
pip install pillow numpy
python tools\make_assets.py
```

脚本做的事：`JOBS` 每行是 `(源文件名, 目标相对路径, 宽, 高, 处理方式)`，处理方式三选一：

- `crop` —— 居中裁剪到目标比例 + LANCZOS 缩放（源图有实底背景，如卡图 / 选人按钮 / 选人背景）
- `cut` —— `cut_background()`：四角采样背景色 → 软阈值抠图 → 高斯羽化 alpha，再居中留白（源图是纯色背景的单个物件，如遗物）
- `alpha` —— 源图自带透明通道，只做等比缩放 + 居中留白，不抠背景（如头像 / 能量图标）
- `scene_box` —— `fit_box()`：按 alpha bbox（阈值 16）裁掉透明边 → 等比缩放到 (宽,高) 框内，不填充画布（场景透明立绘图）

另外自动派生两张：

- 由 `char/hud.png` 派生纯白剪影 `hud_outline.png`
- 由 `char/select.png` 派生去饱和压暗的 `select_locked.png`

要加新图：在 `tools/make_assets.py` 的 `JOBS` 列表里加一行即可。

## 代码接入点

资源路径统一走 `MyCharAssets`（`src/MyChar/MyCharAssets.cs`）：

```csharp
MyCharAssets.CharacterSelect        // res://MyChar/images/char/select.png
MyCharAssets.CharacterSelectLocked
MyCharAssets.CharacterHud
MyCharAssets.CharacterHudOutline
MyCharAssets.Card("strike")         // res://MyChar/images/cards/strike.png
MyCharAssets.Relic("ember_heart")   // res://MyChar/images/relics/ember_heart.png
MyCharAssets.EnergyBig              // res://MyChar/images/ui/energy_big.png
MyCharAssets.EnergyText             // res://MyChar/images/ui/energy_text.png
```

> 不要用本体的 `ImageHelper.GetImagePath()` —— 它固定拼 `res://images/`，指的是**本体**资源，
> 不是本 mod 的。

### 角色（`Character/MyChar.cs`）

| 属性 | 接的资源 |
| --- | --- |
| `CustomCharacterSelectIconPath` | `char/select.png` |
| `CustomCharacterSelectLockedIconPath` | `char/select_locked.png` |
| `CustomIconTexturePath` | `char/hud.png` |
| `CustomIconOutlineTexturePath` | `char/hud_outline.png` |
| `CustomCharacterSelectBg` | 场景 `select_bg.tscn` |
| `CustomVisualPath` | 场景 `creature_visuals.tscn` |

### 场景接入（`.tscn`，已落地）

场景类资源（选人背景 / 战斗立绘 / 商店 / 火堆）已不再用 ironclad 占位，接入方式：

1. **手写文本格式 `.tscn`**，放 `src/MyChar/scenes/`（**不能**放 `assets/` 下——PckPacker
   遇到 `.tscn` 会 exit 2 且整个 pck 都不打）。
2. 贴图引用走 pck 里已有的 `.import` 重映射路径，如
   `[ext_resource type="Texture2D" path="res://MyChar/images/scene/combat.png.import" id="1"]`。
3. `build.ps1` 在 PckPacker 之后跑 `tools/pck_append.py`，把 `.tscn` 追加进 pck 目录
   （Chizuru 皮肤 mod 验证过：游戏可以直接加载 pck 里的文本 `.tscn`，无需 Godot 导出），
   随后跑 `tools/pck_verify.py` 按 Godot 的真实读法校验目录（**路径字段的 4 字节补齐必须算在
   `plen` 之内**，写错会让整个 pck 在游戏里失效，见 01「校验 pck」）。

各场景必需节点（照抄本体场景结构）：

| 场景 | 必需 unique 节点 | 说明 |
| --- | --- | --- |
| `creature_visuals.tscn` | `%Visuals`、`%Bounds`、`%IntentPos`、`%CenterPos`、`%SpineBody`(可空) | BaseLib 转成 `NCreatureVisuals`；静态图安全，`NCreature` 无 Spine 动画时不建动画器 |
| `select_bg.tscn` | 无特殊要求 | 全屏 Sprite2D 即可 |
| `rest_site.tscn` | 无特殊要求 | `NRestSiteCharacter._Ready` 只对真正的 SpineSprite 播动画 |
| `merchant.tscn` | 见下 | `_Ready` 会把 `GetChild(0)` 包成 `MegaSprite` 播 Spine 动画，非 Spine 子节点会抛异常 |

商店场景的处理：`StaticBodyVisualsPatch`（Harmony 前缀）在玩家角色时跳过
`NMerchantCharacter._Ready` 的 Spine 动画段，只保留静态立绘；同一个补丁还在玩家
死亡时把 `%Visuals` 切到 `%DefeatSprite`（败北图）、复活时切回。

### 卡牌（`Cards/*.cs`）

每张牌 override 一个：

```csharp
public override string? CustomPortraitPath => MyCharAssets.Card("strike");
```

加新卡图 = 加一张 `cards/<name>.png` + 新牌里写一行 `MyCharAssets.Card("<name>")`。

### 遗物（`RelicImageOverridePatch`）

遗物没有 override 点，走 BaseLib 的注册表，在 `ModEntry.RegisterRelicIcons()` 里登记：

```csharp
RelicImageOverridePatch.AddOverride<MyCharStarterRelic>(
    new RelicIconData(big, packed, outline));
```

`RelicIconData` 三个字段：

| 字段 | 本体默认路径 | 用途 |
| --- | --- | --- |
| `BigIconPath` | `res://images/relics/<name>.png` | 图鉴 / 拾取弹窗大图 |
| `PackedIconPath` | `res://images/atlases/relic_atlas.sprites/<name>.tres` | 局内小图标 |
| `PackedIconOutlinePath` | `res://images/atlases/relic_outline_atlas.sprites/<name>.tres` | 描边 |

现在三格都填同一张 256×256 占位图。要做精致的话，`packed` 单独出一张小图（如 64×64）。

遗物类里的 `IconBaseName` 保留为兜底：万一注册没生效，退回本体同名图标。

### 药水（`Potions/*.cs`）

药水有 override 点，每瓶各写一行：

```csharp
public override string? CustomPackedImagePath => MyCharAssets.Potion("temp_protocol");
public override string? CustomLargeImagePath => MyCharAssets.Potion("temp_protocol");
```

`CustomPackedImagePath` 是局内槽位图，`CustomLargeImagePath` 是图鉴 / 提示大图。因为槽位按
`keep-aspect` 缩到 60×60，一张 256×256 图两处共用即可，不必各出一张。

加新药水 = 加一张 `potions/<name>.png` + 药水类里写两行 `MyCharAssets.Potion("<name>")` +
类上加 `[Pool(typeof(MyCharPotionPool))]`。

### 能量图标（`MyCharCardPool` / `MyCharTokenCardPool`）

能量图标路径是 `EnergyIconHelper.GetPath(EnergyColorName)` 算出来的，而 BaseLib 的补丁只认带
分隔符 `∴` 的 `EnergyColorName`。所以两个卡池**不要**覆盖 `EnergyColorName`（基类给的就是
`card_pool∴MY_CHAR_CARD_POOL` 这种形式），只实现 `ICustomEnergyIconPool` 的两个属性：

| 属性 | 接的资源 | 用途 |
| --- | --- | --- |
| `BigEnergyIconPath` | `ui/energy_big.png` | 卡面费用 / 大图标 |
| `TextEnergyIconPath` | `ui/energy_text.png` | 描述内联 `[E]` |

覆盖成 `EnergyColorName => "ironclad"` 会退回本体图标（旧占位做法）。改 `EnergyColorName` 是安全的：
本体的「多彩哲学家」事件只遍历它自己硬编码的 5 个卡池，不会碰到本 mod 的池子。

> 局内左下角的**能量计数器**（那个球）不是贴图，是 `.tscn` 多层场景，见 01。
