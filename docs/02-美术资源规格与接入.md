# 02 · 美术资源规格与接入

## 尺寸规格

尺寸是从本体 / 现成角色 mod 的 `.pck` 里读 `CompressedTexture2D` 头量出来的，不是猜的。

| 用途 | 尺寸 | 说明 |
| --- | --- | --- |
| 卡图 | **500 × 380** | 注意不是 4:3 的 500×375 |
| 选人界面按钮图 | **132 × 195** | 竖版 |
| 选人界面未解锁图 | 132 × 195 | 由按钮图去饱和 + 压暗派生 |
| 顶部栏角色头像 | **128 × 128** | Modder's Manual 写的 88×88 是错的 |
| 头像描边（剪影） | 128 × 128 | 纯白剪影，顶部栏用它上色描边 |
| 遗物图标 | **256 × 256** | 图鉴大图 / 局内小图标暂时共用 |
| 战斗立绘 | 512 × 512 | 备用图；真立绘要走 .tscn，见 01 |

## 目录结构

```
.artwork/raw/                 ← 原始图（jpg/png 都行，不参与打包）
src/MyChar/assets/images/     ← 处理后的成品，会被打进 pck
    char/    portrait.png  select.png  select_locked.png  hud.png  hud_outline.png  combat.png
    cards/   strike.png  defend.png  blast.png  ward.png  signature.png
    relics/  ember_heart.png  old_anchor.png
```

`.artwork/raw/` 只放源图，**不要**放进 `assets/`，否则会被打进 pck 白白增大体积。

## 处理流程

```powershell
# 依赖 Pillow + numpy
pip install pillow numpy
python tools\make_assets.py
```

脚本做的事：

- 按目标比例居中裁剪 + LANCZOS 缩放
- 遗物图标走 `cut_background()`：四角采样背景色 → 软阈值抠图 → 高斯羽化 alpha
- 由 `char/hud.png` 派生纯白剪影 `hud_outline.png`
- 由 `char/select.png` 派生去饱和压暗的 `select_locked.png`

要加新图：在 `tools/make_assets.py` 的 `JOBS` 列表里加一行 `(源文件名, 目标相对路径, 宽, 高, 是否抠背景)`。

## 代码接入点

资源路径统一走 `MyCharAssets`（`src/MyChar/MyCharAssets.cs`）：

```csharp
MyCharAssets.CharacterSelect        // res://MyChar/images/char/select.png
MyCharAssets.CharacterSelectLocked
MyCharAssets.CharacterHud
MyCharAssets.CharacterHudOutline
MyCharAssets.Card("strike")         // res://MyChar/images/cards/strike.png
MyCharAssets.Relic("ember_heart")   // res://MyChar/images/relics/ember_heart.png
```

> 不要用本体的 `ImageHelper.GetImagePath()` —— 它固定拼 `res://images/`，指的是**本体**资源，
> 不是本 mod 的。

### 角色（`Character/MyChar.cs`）

| 属性 | 接的资源 |
| --- | --- |
| `CustomCharacterSelectIconPath` | `char/select.png` |
| `CustomCharacterSelectLockedIconPath` | `char/select_locked.png` |
| `CustomIconTexturePath` | `char/hud.png` |
| `CustomIconOutlineTexturePath` | `char/hud_outline.png` |

场景类属性（`CustomVisualPath` / `CustomIconPath` / `CustomEnergyCounterPath` /
`CustomRestSiteAnimPath` / `CustomMerchantAnimPath` / `CustomCharacterSelectBg`）
继续沿用 `PlaceholderCharacterModel` 给的 ironclad 占位场景。

### 卡牌（`Cards/*.cs`）

每张牌 override 一个：

```csharp
public override string? CustomPortraitPath => MyCharAssets.Card("strike");
```

加新卡图 = 加一张 `cards/<name>.png` + 新牌里写一行 `MyCharAssets.Card("<name>")`。

### 遗物（`RelicImageOverridePatch`）

遗物没有 override 点，走 BaseLib 的注册表，在 `ModEntry.RegisterRelicIcons()` 里登记：

```csharp
RelicImageOverridePatch.AddOverride<MyCharStarterRelic>(
    new RelicIconData(big, packed, outline));
```

`RelicIconData` 三个字段：

| 字段 | 本体默认路径 | 用途 |
| --- | --- | --- |
| `BigIconPath` | `res://images/relics/<name>.png` | 图鉴 / 拾取弹窗大图 |
| `PackedIconPath` | `res://images/atlases/relic_atlas.sprites/<name>.tres` | 局内小图标 |
| `PackedIconOutlinePath` | `res://images/atlases/relic_outline_atlas.sprites/<name>.tres` | 描边 |

现在三格都填同一张 256×256 占位图。要做精致的话，`packed` 单独出一张小图（如 64×64）。

遗物类里的 `IconBaseName` 保留为兜底：万一注册没生效，退回本体同名图标。

| 资源 | 接入点 |

**预留的 2 张（暂未接入，先占位）**：

| 资源 | 说明 |
| --- | --- |
| `char/portrait.png`（256×256） | BaseLib 的角色模型没有"角色大立绘"贴图 override（`InitialPortraitPath` 是 EventModel 的），留着备用 |

现在留着是为了后续做场景时直接有素材。

这些是 AI 生成的临时素材，正式美术直接替换同名文件，再跑一次
`python tools\make_assets.py` + `.\tools\build.ps1 -Deploy` 即可。
