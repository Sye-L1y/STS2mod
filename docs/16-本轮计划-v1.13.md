## 2. 本轮落地

### 2.1 调节 `Adjustment`（稀有 · 能力 · 2（1）费）

- 效果：**每回合第一次**打出迭代牌时，该牌回到手牌（所有迭代牌**共用**一次，规则 **P4**）。
- 拆分职责：
  - `AdjustmentPower`（`StackType.Single`）只记**额度**：`TryConsumeTurnSlot(player)` 花额度、`AfterPlayerTurnStart` 每回合刷回；
    状态栏用 `IAddDumbVariablesToPowerDescription` 显示「未使用 / 已使用」。
  - 真正的回手在 `AlphaCard.AfterCardPlayedLate`（**引擎已把打出的牌移出出牌区之后**的时机）统一做：
    `_returnToHandAfterPlay`（回手传参）**或** `AdjustmentPower` 额度 → `CardPileCmd.Add(this, PileType.Hand)`。
- **不会无限循环**：回手本身不花额度，只有「打出迭代牌」才花，额度每回合只有一次（P4 + 07 §6 的 R1）。

### 2.2 语义附加 `SemanticAttach`（罕见 · 技能 · 1（0）费 · 消耗）

- 效果：选一张**没有响应**的手牌，使其获得**响应**。
- 机制新增 **E24**：
  - `AlphaCard.GrantResponse()` + `HasResponse => IsResponse || _grantedResponse`；
  - **所有机制判断改读 `HasResponse`**：`CanonicalKeywords` / `OnPlay` 步骤 1 / `PreviewDamageAddFor` / `PreviewBoostFor`；
  - 外部筛选点同步：`Call.IsLinked`、`DisparityCount.IsDisparate`。
- 选牌用 `CardSelectCmd.FromHand(...)` + `SelectionScreenPrompt`，`IsAttachable = card != this && card is AlphaCard a && !a.HasResponse`；
  手牌无合法目标时**照常打出**（不弹窗、不卡手）。
- 规则 **P12**：只**本场战斗**有效（挂手牌实例，战斗结束即消失，不写回牌组）；只对**自家牌**生效。

## 3. 引擎事实（本轮新增，可复用）

1. **回手必须晚于引擎移牌**：`AfterCardPlayed` 阶段牌可能还在出牌区，紧接着会被移到弃牌堆；
   `AfterCardPlayedLate` 才是「已经不在手牌」的稳定时机（本 mod「回手」传参、零基启动、现在的调节都放这里）。
2. **Power 也能收到 `AfterCardPlayedLate`**（钩子由 `AbstractModel` 提供，`IterateHookListeners()` 覆盖 `creature.Powers`），
   但**回手动作放在卡牌自己那一侧更稳**（牌自己最清楚自己现在在哪个牌堆）。
3. **`CustomPowerModel` 有 `InvokeDisplayAmountChanged()`**：额度/状态变化时调一次，状态栏文案才会刷新。

## 6. 已知近似 / 待实测观察

1. **语义附加授予的响应不写回牌组**：同一张实体牌在**下一次战斗**里又会变回原样（战斗实例是新的）——这是设计口径（P12），若你想让它跨战斗就必须写进牌组实体（当前不做）。
2. **调节 + 0 费迭代牌**：额度用完就不再回手，理论上安全；实测若发现某条路径能绕过额度，回报即可。
3. **灵魂记忆触发传参**（v1.12 遗留观察项）：依赖「本次打出快照」的牌（如战斗预设）被触发时值可能为 0。
