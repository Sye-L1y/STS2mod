## 2. 本轮落地的 3 张牌

### 2.1 击打测试 `StrikeTest`（罕见 · 攻击 · 1 费）

造成 9（12）伤；**传参：响应牌下一次打出回到手牌**。

**新增「回手」传参（E1 的 回手 项）**：

1. `ParamEntry.ParamKind` 新增 **`ReturnToHand`**（池 tooltip 显示「响应牌结算后回到手牌」）；
2. 击打测试 `BuildParam()` 抛一条 `ReturnToHand`；
3. 响应牌消费到它时，`AlphaCard.ApplyParam` 只置一个**本次结算标记**（无即时效果）；
4. `AlphaCard.AfterCardPlayedLate` 里「本牌自己被打出 && 标记为真」→ `CardPileCmd.Add(this, PileType.Hand)`；
5. 条目随本次响应的 `ConsumeParams()` 清出池子，标记用完即清 → **不写在牌上**（符合 P10）。

> 与本体 Bolas / MakeItSo、以及本 mod 的 E16（零基启动回手）**同一套 AfterCardPlayedLate 口径**，不引入新范式。
> 「特殊的除外」（消耗 / 虚无类）本轮**未特判**，等实测遇到再按牌 override。

### 2.2 预输入 `PreInput`（罕见 · 技能 · 1 费 → 升级 0 费）

**下一次响应不消耗传参**（池原样保留给再下一次）。

- 载体：`AlphaCorePower.Data.NextResponseFree` + `SetNextResponseFree()` / `TakeNextResponseFree()`（取用即消耗，只生效一次）。
- 判定：`AlphaCard.OnPlay` 响应阶段 `ConsumesParams && core.HasParams && core.TakeNextResponseFree()`。
  **池空时不消耗额度**——额度留到真正有传参可保的那次响应，避免被空响应白白吃掉。
- 只影响**会消费**的响应牌；继承迭代本来就 `PeekParams()`，不吃这枚额度。

### 2.3 数据模拟 `DataSimulation`（罕见 · 攻击 · 2 费）

造成 12（18）伤；**迭代2：伤害翻倍**。

- `IterationEvery = 2`；`IterationStacks > 0` 时 `damage *= 2`（乘在本次增幅之后的原始值上）。
- 卡面不显示翻倍后的数字（文案写「伤害翻倍」），数值随实战结算。

## 3. 多多益善占位图配色修正

- **现象**：`more_the_merrier` 是**技能**牌，占位图却按**攻击**（红 `(198,84,72)`）生成。
- **原因**：v1.9 第十六轮只核对了「图上的卡名」，没检查配色，所以记作无误。
- **修正**：`tools/make_alpha_cards.py` 里 `("more_the_merrier", "多多益善", ATTACK)` → `SKILL`，重新生成后为**蓝色技能底**。

## 4. 下一批安排（Q5 我的决定）

**先做「不依赖 E1 剩余设计稿」的牌**——因为 E1 现在只剩「多状态一次」没定，「动态值」按现状评估不需要；把能直接写的先清掉，比干等设计确认更划算。

已排顺序（下一轮 v1.12）：

| 优先 | 牌 | 依赖 | 备注 |
| --- | --- | --- | --- |
| 1 | 冷息（能力）：迭代牌获得**保留** | 无 E1 | 需要一个「回合末把手牌里的迭代牌留手」的载体 Power |
| 2 | 攻守兼备（攻击）：8（10）伤；传参：响应牌造成伤害时获得等量格挡 | 新 `ParamKind`（伤害→格挡） | 中等 |
| 3 | 异常解析（技能）：消耗手牌所有状态牌；随机给一个敌人 X（+1）层脆弱/虚弱/易伤 | 无 E1（直接结算） | 中等 |
| 4 | 二次输入（普通攻击）：7（10）伤；传参池非空则**重复上一次的传参** | 需定义「上一次的传参」口径 | **待你确认口径** |
| 5 | 多层网络输出（罕见攻击 X）：7（9）伤 ×X；响应；击杀敌人则战斗结束后随机升级一张牌 | 无 E1 | 中等（战后升级需要挂到 run 结算） |
| 6 | 灵魂记忆（罕见技能） | 需「灵魂」牌 + 选抽牌堆带传参的牌触发 | 最复杂，排最后 |

> **待你拍板**：第 4 张「重复上一次的传参」——是指「把**最近一次入池**的那条传参再作用一遍在本牌上」，还是「重复**上一次打出的牌**所带的传参」？两种实现差很多。
